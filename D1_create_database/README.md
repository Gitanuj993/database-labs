# About


## How to show databases

```sql
show databases ;
```
By using above query we can see all the database present on the server/machine

## How to Create a New database ?

```sql 
CREATE DATABASE <database_name> ;
```
Example

```sql
CREATE DATABASE mydb1 ;
```

## How to select a Database 

```sql 
use <databse_name> ;
```

Example

```sql
use mydb1 ;
```


> [!note]
> Clear the terminal Screen 

Use 
```sql
system cls ;
```
